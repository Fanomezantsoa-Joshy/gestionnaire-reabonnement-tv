# Gestion des réabonnements TV

## Description

Application desktop développée en C# avec Windows Forms et MySQL, permettant de gérer les réabonnements TV ainsi que les différentes informations liées aux clients, aux offres et aux chaînes.

L'accès à l'application est sécurisé par un système d'authentification des utilisateurs.

## Fonctionnalités

* Authentification des utilisateurs pour sécuriser l'accès à l'application
* Gestion des clients
* Gestion des offres d'abonnement
* Gestion des chaînes TV
* Gestion des réabonnements TV

## Technologies utilisées

* C#
* Windows Forms
* .NET
* MySQL
* XAMPP
* Visual Studio

## Base de données

L'application utilise une base de données MySQL pour stocker et gérer les informations relatives aux utilisateurs, aux clients, aux offres, aux chaînes et aux réabonnements.

Le script SQL permettant de créer la base de données est disponible dans le dossier database.

## Installation et configuration

* Installer Visual Studio avec les composants nécessaires au développement Windows Forms.
* Installer XAMPP.
* Démarrer le serveur de base de données.
* Créer une base de données nomée streamlinedb et importer script SQL fourni dans le dossier database.
* Ouvrir le fichier solution '.sln' dans Visual Studio.
* Compiler et exécuter l'application.
* Un compte de teste est déjà disponnible (Nom : Admin, Mot de passe : motdepasse).
